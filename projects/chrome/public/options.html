Snapshots

Importing a previously exported snapshot is not directly possible in the extension's popup window. This is due to the browser's limitation of automatically closing the popup when it loses focus, making it impossible to drop or select a file there.

To circumvent this limitation, you need to upload your snapshot here and make it available for the extension to import in the popup.

Uploading a snapshot here does NOT automatically start an import!

The data remains inside this browser and is NOT uploaded to any server!
